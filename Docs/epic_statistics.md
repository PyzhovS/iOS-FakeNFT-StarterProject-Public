# Эпик: Экран статистики (Statistics Screen)

## 1. Цель
Реализовать экран рейтинга пользователей NFT-приложения

## 2. Основной функционал
- Просмотр таблицы с пользователями
- Сортировка рейтинга по критериям (по имени, по количеству NFT, по месту)
- Открытие профиля пользователя при нажатии на ячейку

## 3. Декомпозиция

### 1/3 эпик
- Создание структуры папок (Statistics)
- Создание StatisticsViewController и базового UI (UITableView)
- Настройка ячеек (пока с мок-данными)
- Подключение контроллера к TabBar

### 2/3 эпик
- Настройка сетевого слоя (URLSession + GCD)
- Загрузка данных рейтинга с mock-сервера
- Обновление таблицы с реальными данными
- Реализация сортировки и сохранения её состояния (UserDefaults)

### Финал
- Добавление экрана профиля пользователя
- Навигация с экрана статистики к профилю
- Тестирование и исправление ошибок
- Улучшение UI
